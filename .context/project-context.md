The context has been separated into specific domains:

- [Product Context](./product-context.md): Vision, UI/UX Guidelines, Current State, and Next Epics.
- [Technical Context](./technical-context.md): Database Architecture and Core Architecture.
- [External Systems](./external-systems.md): Documentation on our usage of MUI, Tailwind CSS, Leaflet, and Supabase.
